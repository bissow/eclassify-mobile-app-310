# Date: 18.04.2026

1. Reference for Setup Firebase for first time: https://wrteam-in.github.io/eclassify-doc/docs/mobile-app/integrate-firebase/
2. Reference for Maps: https://wrteam-in.github.io/eclassify-doc/docs/mobile-app/google-map/
3. Reference for Notification: https://wrteam-in.github.io/common_app_doc/GeneralSettings/notifications/
2. First Create a project and then create Android App and Web App under that particular project.
2. Then go to that Project settings → Service accounts and Generate Private Key, Now a .Json file would be downloaded and keep it safe place.
3. Then go to https://console.cloud.google.com/ and select that Firebase project name because Firebase is now integrated with the Google Cloud.
4. Go to "APIs & Services" and Click to  "+ Enable APIs and services" Then Add and Enable these services one by one:
   1. Maps SDK for Android
   2. Maps SDK for iOS
   3. Geocoding API
   4. Geolocation API
   5. Places API
   6. Maps JavaScript API (This is optional as it is used for website so, I have added this also for web version)
5. After that, you can go to "APIs & Services" under that project. then go to "Credentials" and select Edit API Key of "Android key (auto created by Firebase)" and then select those 5 or 6 location services for in "Select API restrictions" and then you may add "Application restrictions" such as website or ip address to protect it misuse by others and Save it.
6. Now Go to Admin Panel → Settings → Map Provider and Paste here the API key which can be found on the "google-services.json" or you can copy from the "APIs & Services" → "Credentials"  → Show Key of "Android key (auto created by Firebase)".
7. Also, this API key can be used for Flutter app set meta-data value of "com.google.android.geo.API_KEY" in the file: `android/app/src/main/AndroidManifest.xml`. Paste or Replace the API key in the placeholder of "YOUR_API_KEY_HERE".
8. To enable Sign in with Google and Apple please see reference: https://wrteam-in.github.io/eclassify-doc/docs/mobile-app/google-signin/ and https://wrteam-in.github.io/common_app_doc/GeneralSettings/firebase#-add-sha1--sha256-keys-in-firebase
9. Open your firebase console → Go to Sign-in method in Authentication → Go to the Google. Enable the Save it.
10. Important: To enable Google sign-in for your Android apps, you must provide the SHA-1 release fingerprint for each app (go to Project Settings > Your apps section).
