For App Icon changes i have used 'flutter_launcher_icons' packages.
Steps:
Add this configuration in `pubspec.yaml`:
```yaml
flutter_launcher_icons:
   android: "launcher_icon"
   ios: true
   remove_alpha_ios: true
   image_path: "assets/images/icon.png" # Path to your 1024x1024 image
   adaptive_icon_background: "assets/images/ic_launcher_background.png" # Or a background image path
   adaptive_icon_foreground: "assets/images/ic_launcher_foreground.png"
   adaptive_icon_monochrome: "assets/images/ic_launcher_monochrome.png"
   adaptive_icon_foreground_inset: 16
```
or
Create a separate file named 'flutter_launcher_icons.yml' and then add above into that file.

# If your configuration is in a separate file (e.g., flutter_launcher_icons.yaml), you must explicitly point to it when running the command:
# dart run flutter_launcher_icons -f flutter_launcher_icons.yaml
