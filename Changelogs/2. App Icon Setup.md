# 📱 App Icon Setup

## 📌 Understanding App Icons

App icons are platform-specific image files responsible for displaying your app’s icon on a device after installation. Both Android and iOS have their own icon requirements, ensuring proper visibility across different screen sizes and resolutions.

To update the app icon, you can:

* Manually replace icon resources in the Android and iOS directories
* Use a package to automate icon generation

---

## 🔧 Automated Method (Recommended)

Use the **Flutter Launcher Icons** package to generate icons easily.

### 1️⃣ Add Dependency

Include the following in your `pubspec.yaml` under `dev_dependencies`:

```yaml
dev_dependencies:
  flutter_launcher_icons: any
```

---

### 2️⃣ Configure Icons

Add this configuration in `pubspec.yaml`:

```yaml
flutter_launcher_icons:
  android: "ic_launcher"
  ios: true
  remove_alpha_ios: true
  image_path: "assets/images/ic_launcher.png"
```

---

### 🔹 Optional Adaptive Icon Settings (Android Only)

```yaml
flutter_launcher_icons:
  adaptive_icon_foreground: "assets/images/ic_launcher_adaptive.png"
  adaptive_icon_background: "#FFFFFF"
  adaptive_icon_monochrome: "assets/images/ic_launcher_monochrome.png"
  adaptive_icon_foreground_inset: 16
```

---

## 🔍 Explanation of Parameters

| Parameter                        | Description                                                              |
| -------------------------------- | ------------------------------------------------------------------------ |
| `image_path`                     | (Required) Main icon file (512×512 recommended) for both Android and iOS |
| `ios`                            | `true` to generate iOS icons, `false` to skip                            |
| `remove_alpha_ios`               | `true` removes alpha layer from iOS icons for App Store upload           |
| `android`                        | Icon name inside Android `res` folder                                    |
| `adaptive_icon_foreground`       | (Optional) Transparent PNG for adaptive icon foreground                  |
| `adaptive_icon_background`       | (Optional) Background color of adaptive icon                             |
| `adaptive_icon_monochrome`       | (Optional) Monochrome icon for Android 13+ themed icons                  |
| `adaptive_icon_foreground_inset` | (Optional) Padding for adaptive icon (default: 16)                       |

> ⚠️ **Note:** If using adaptive icons, ensure asset paths are registered under `assets` in `pubspec.yaml`.

---

### 3️⃣ Generate Icons

Run the following command:

```bash
dart run flutter_launcher_icons
```

🔹 **Tip:** Delete any existing icons with different shapes to prevent conflicts.

✅ After running this command, your app will have updated icons across Android and iOS!

---

## 🛠️ Manual Method (Optional)

If you prefer not to use the package, you can manually replace icon files.

💡 You can use free online tools to generate all required icon sizes from a single image.

---

## 📱 Android

### Required Steps:

* Prepare icon assets in resolutions like:

    * 48×48, 72×72, 96×96, 144×144, 192×192

* Replace default icons in:

```
android/app/src/main/res/
```

### Replace these files:

```
mipmap-mdpi/ic_launcher.png
mipmap-hdpi/ic_launcher.png
mipmap-xhdpi/ic_launcher.png
mipmap-xxhdpi/ic_launcher.png
mipmap-xxxhdpi/ic_launcher.png
```

### Adaptive Icons (if applicable):

```
mipmap-anydpi-v26/ic_launcher.xml
mipmap-anydpi-v26/ic_launcher_round.xml
```

### Optional Layers:

```
res/drawable/ic_launcher_foreground.xml
res/drawable/ic_launcher_background.xml
```

---

## 🍏 iOS

### Required Steps:

* Prepare icons based on Apple’s required sizes
* Replace icons in:

```
ios/Runner/Assets.xcassets/AppIcon.appiconset/
```

* Replace all `.png` files
* Update `Contents.json` if needed (or regenerate using Xcode)

---

## 🔄 Apply Changes

After manual replacement, run:

```bash
flutter clean
flutter pub get
flutter run
```

---

✅ Your app icons should now be updated successfully across both platforms!
